# Portfolio de Gabriel Nganty

Portfolio personnel de Gabriel Nganty, software engineer basé à Douala. Le site présente son profil, ses projets, ses compétences et ses certifications.

## Prérequis

- Node.js
- npm

## Installation

```bash
npm install
npm run dev
```

Vite affiche l’adresse locale à ouvrir dans le navigateur.

## Commandes

```bash
npm run dev      # lancer le serveur de développement
npm run build    # générer le site dans dist/
npm run preview  # prévisualiser le build
```

## Formulaire de contact

Le formulaire utilise Web3Forms. Copiez `.env.example` vers `.env`, puis renseignez votre clé d’accès :

```env
VITE_WEB3FORMS_KEY=votre_cle_web3forms
```

Ne publiez pas le fichier `.env` ni votre clé d’accès.
